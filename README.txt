# GradeVision — Predict Your Potential

![GradeVision Banner](https://img.shields.io/badge/GradeVision-CGPA%20Calculator-brightgreen)
![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

GradeVision is a powerful **CGPA Calculator & Final Exam Predictor** designed for university students. It helps you track your academic performance, calculate your CGPA from transcripts, and predict exactly how many marks you need in finals to achieve a 4.0 GPA.

---

## ✨ Features

### 📊 Semester Predictor
- Add multiple courses with assignments, mids, projects, and finals
- **Project Mode Toggle** — automatically adjusts mark limits (Mids: 15, Project: 15)
- **Show 4.0 Needed Toggle** — displays exact marks required in finals for a 4.0 GPA
- Real-time GPA calculation based on your grading scale
- Interactive progress graph showing percentage per course

### 📜 Transcript Vault
- Upload **Excel files** (automatically finds course data from AIOU transcript format)
- Upload **PDF files** (extracts course codes, names, credits, and marks)
- Manual course entry with add/remove functionality
- **Overall CGPA Card** — displays CGPA, Grade, Total Credits, and Quality Points
- GPA trend graph showing performance across all courses

### 🎨 Design
- Clean, modern interface with **glassmorphism** effect
- **Rebellion-style landing page** with click-to-start animation
- Smooth tab transitions between Predictor and Transcript
- Dark theme with gradient accents (Cyan, Purple, Green)
- Fully responsive for mobile, tablet, and desktop
