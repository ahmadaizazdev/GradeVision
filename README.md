## ⚡ About

GradeVision is a **smart academic predictor tool** that helps students calculate CGPA, predict final exam requirements, and track semester performance in real time.

> 🎯 Built for students who want clarity before exams, not after results.

---

## ✨ Features

<details>
<summary>📊 CGPA & GPA Tools</summary>

- Semester-wise GPA calculation  
- Full transcript CGPA support  
- Excel upload (AIOU format supported)  
</details>

<details>
<summary>🎯 Prediction System</summary>

- 4.0 GPA target calculator  
- Final exam marks prediction  
- “What do I need in finals?” logic engine  
</details>

<details>
<summary>📈 Visualization</summary>

- Real-time performance graphs  
- Animated progress tracking  
</details>

<details>
<summary>🎨 UI/UX</summary>

- Glassmorphism design  
- Dark modern theme  
- Fully responsive layout  
</details>

## 🎯 Grading Logic

<details>
<summary>Click to view GPA scale</summary>

| Marks  | Grade | GPA  |
| ------ | ----- | ---- |
| 85–100 | A     | 4.00 |
| 80–84  | A-    | 3.67 |
| 75–79  | B+    | 3.34 |
| 71–74  | B     | 3.00 |
| 68–70  | B-    | 2.67 |
| 64–67  | C+    | 2.34 |
| 61–63  | C     | 2.01 |
| 58–60  | C-    | 1.67 |
| 54–57  | D+    | 1.31 |
| 50–53  | D     | 1.00 |
| <50    | F     | 0.00 |

</details>
